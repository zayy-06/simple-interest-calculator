# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to this project!

All contributions are welcome. You can help improve this project by reporting bugs,
suggesting enhancements, improving documentation, or sharing new ideas.

## Bug Reports

If you find a bug, please open an issue and provide:

- A clear description of the bug
- Steps to reproduce the problem
- Expected behavior
- Actual behavior

## Documentation Improvements

Documentation improvements are welcome. You can improve explanations, examples,
instructions, or other documentation related to the project.

## Enhancements

Suggestions and enhancements are encouraged. Please describe the proposed
improvement clearly and explain how it would benefit the project.

## Ideas

New ideas and suggestions are always welcome. Open an issue to discuss your idea
before making major changes.

## Pull Requests

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes.
6. Create a pull request.

Thank you for contributing!
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.
